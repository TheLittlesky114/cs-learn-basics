# C# 基础 · 核心语法进阶

跟随唐老狮 C# 教程整理的第二阶段练习仓库。语法打底（变量、运算符、流程控制）之后，从**枚举**一路练到**选择排序**，共 **22 个可运行的控制台项目**。

每个项目是一个独立的 `.csproj`，单文件 `Program.cs`，按知识点用 `#region` 分段，注释直接写在对应代码上方。知识点项目和配套练习题各占一半，适合边读边跑。

- **语言 / 平台**：C# / .NET 10.0（`net10.0`），控制台应用
- **项目数量**：22 个独立 `.csproj`
- **代码规模**：约 2,600 行，零第三方依赖
- **解决方案**：根目录 `c#基础.slnx` 统一组织
- **用途**：个人学习记录、语法查阅、教学演示

## 仓库范围

这个仓库**只包含核心语法进阶这一段**：

| 阶段 | 内容 | 是否在本仓库 |
| --- | --- | --- |
| 语法基础 | 变量、类型转换、运算符、条件分支、循环 | ✗ |
| **核心语法进阶** | **枚举、数组、函数、结构体、排序** | **✓ 本仓库** |
| 常用 API 实战 | 控制台坐标 / 颜色 / 光标，营救公主小游戏 | ✗ |

前置的语法基础和后续的控制台 API 实战分别在另外的仓库，本仓库可以独立克隆、独立编译、独立运行。

## 学习路线

这 22 个项目不是并列的目录，而是一条递进的线：

```
枚举 ──► 数组 ──► 函数 ──► 结构体 ──► 排序
给状态起名   批量存数据   拆逻辑     打包数据+行为   算法入门
```

- **枚举**解决「状态用 1/2/3 记不清含义」的问题；
- **数组**（一维 → 二维 → 交错）解决「一堆同类型数据怎么存」；
- **函数**（含 `ref`/`out`、变长参数、重载、递归）解决「逻辑怎么拆」；
- **结构体**把数据和方法打包在一起，是面向对象之前的一次预演；
- **排序**用冒泡和选择两种最直观的算法收尾，练习双重循环的实际用途。

## 运行方式

### 命令行（.NET SDK）

需要 **.NET 10.0 SDK**。

```bash
# 编译整个解决方案（22 个项目）
dotnet build "c#基础.slnx"

# 运行某一课
dotnet run --project "Lesson1枚举/Lesson1枚举.csproj"
dotnet run --project "Lesson13冒泡排序/Lesson13冒泡排序.csproj"
```

路径含中文或空格时必须加引号，例如：

```bash
dotnet run --project "Lesson8 ref和out/Lesson8 ref和out.csproj"
dotnet run --project "Lesson9变长参数和参数默认值/Lesson9变长参数和参数默认值.csproj"
```

### Visual Studio

用支持 `.slnx` 的版本（VS 2022 17.13+ / VS 2026）打开根目录的 `c#基础.slnx`，把目标项目设为启动项目后按 F5。解决方案内全部是相对路径，克隆到任意目录都能直接打开。

部分项目需要用 `Console.ReadLine()` 交互输入（如 `Lesson8 ref和out` 的登录示例、`Lesson1枚举练习题` 的咖啡下单），直接在真实控制台窗口运行即可。

## 代码约定

- 每个示例在 `Main` 中用 `#region 知识点一 / 知识点二 …` 分段，注释写在对应代码上方；
- 被注释掉的代码通常是「反例」或「错误写法演示」，用来讲清楚语法限制，不是遗留垃圾；
- 练习题目录名统一为 `<课次>练习题`，与知识点项目一一对应；
- 所有项目都是 `net10.0` + `ImplicitUsings` + `Nullable` 开启，编译时可能出现可空引用、未使用变量等警告，均来自教学示例本身，不影响运行。
